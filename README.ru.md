# MEDZH VPN

**Нужен телевизор LG webOS с root и Homebrew Channel в состоянии «Root OK».** Без root приложение работать не может: webOS не даёт обычным приложениям создавать TUN, менять маршруты и DNS.

[English](README.md)

VPN-клиент для LG webOS на основе [sing-box](https://github.com/SagerNet/sing-box) (ARMv7) и небольшого контроллера на Node.js, который уже есть на ТВ. Приложение **MEDZH VPN** включает и выключает VPN для всего телевизора, восстанавливает обычную сеть при сбое и умеет подключаться автоматически при включении ТВ.

> **Статус: beta.** Проверено на одной модели (LG 55UA75009LA, webOS 25); другие LG с root должны работать, если проходят проверки экрана установки (см. ниже). Компоненты ставятся из самого приложения; профили добавляются с телефона по QR-коду или с флешки.

## Дисклеймер

- Программа предоставляется «как есть», без каких-либо гарантий (см. [LICENSE](LICENSE)).
- Root и изменение сетевых настроек ТВ — на ваш риск. Проект не трогает прошивку и системные разделы, но ошибка в сетевых настройках может временно оставить ТВ без интернета (см. «Восстановление сети»).
- **Kill switch нет.** Пока VPN не подключён (включение ТВ, сбой сервера, повторы до 5 минут, смена сети), весь трафик ТВ идёт напрямую через обычный интернет, без VPN. Приложение в это время показывает «Обычный интернет».
- Нужен **собственный** VPN-сервер или профиль, которым вы вправе пользоваться. Проект не предоставляет серверов.
- Соблюдайте законы своей страны.

## Что поддерживается сейчас

- Профили (ссылки или outbound из JSON sing-box):
  - `vless://` — без шифрования / TLS / Reality; транспорт TCP, WebSocket (в том числе early data `?ed=`), gRPC, HTTPUpgrade; `flow=xtls-rprx-vision`;
  - `vmess://` (base64 JSON v2rayN, `alterId` 0), `trojan://`, `ss://` (SIP002 и старый base64; шифры AEAD и 2022, без плагинов), `hysteria2://` / `hy2://` (obfs salamander, смена портов), `tuic://`.
  - Ссылки в том виде, как их выдают Marzban, 3x-ui, Remnawave и Hiddify, принимаются (образцы в `test/panels.test.cjs`). Их дополнительные параметры переводятся в настройки sing-box, где есть аналог (TLS `fragment`, obfs `gecko` у Hysteria2, `upmbps`/`downmbps`), или отбрасываются, если sing-box в них не нуждается (служебные метки, `spx`, `pqv`, настройки mux, трюки со смешанным регистром и паддингом, привязка к сертификату без `insecure`); где это важно, у профиля остаётся пометка.
  - Ссылка, отключающая проверку сертификата (`allowInsecure=1`, `insecure=1`), отклоняется: такой сервер может подменить любой, кто находится на пути трафика, и прочитать туннель. Нужен сервер с настоящим сертификатом или Reality. Такой профиль, сохранённый версией 0.6.1 или старше, продолжает работать и помечен «без проверки сертификата».
  - Отклоняется, а не меняется молча: незнакомый параметр, ECH, `authority` у gRPC, отличный от имени сервера, режим gRPC `multi`, привязка к сертификату вместе с `insecure`, плагины и TLS у Shadowsocks и возможности только Xray (xhttp, kcp, VLESS encryption, трюки `fm`) — с пояснением «не поддерживается sing-box». Сервер с IPv6-адресом не поддерживается.
  - Сервер может быть доменом: он резолвится обычным DNS телевизора до запуска туннеля. VPN считается подключённым, если trace Cloudflare через туннель показывает адрес сервера или адрес выхода, отличный от прямого адреса ТВ.
- Весь IPv4-трафик ТВ идёт через VPN, DNS — через DoH внутри туннеля. Внешний IPv6 во время VPN блокируется. Локальная сеть доступна.
- Если сервер недоступен, контроллер возвращает обычную сеть и повторяет подключение с паузами до 5 минут. Отдельный watchdog восстанавливает сеть, если контроллер завис.

## Установка

1. **Root и Homebrew Channel.** Получите root способом, подходящим для прошивки вашего ТВ (см. [webosbrew.org/rooting](https://www.webosbrew.org/rooting/)), и убедитесь, что в Homebrew Channel → Settings указано «Root OK».
2. **Скачайте** `io.github.steam20011972-code.tvvpn_<версия>_all.ipk` и файл `.sha256` из [Releases](https://github.com/steam20011972-code/tv-vpn/releases) и проверьте: `sha256sum -c io.github.steam20011972-code.tvvpn_<версия>_all.ipk.sha256`.
3. **Установите IPK** через [webOS Dev Manager](https://github.com/webosbrew/dev-manager-desktop), командой `ares-install --device <tv> <файл>.ipk` или по SSH: скопируйте его в `/tmp/tv-vpn.ipk` и выполните
   `luna-send -i -f luna://com.webos.appInstallService/dev/install '{"id":"io.github.steam20011972-code.tvvpn","ipkUrl":"/tmp/tv-vpn.ipk","subscribe":true}'`.
4. **Откройте MEDZH VPN → «Установить компоненты».** Приложение проверит телевизор (см. ниже), скопирует ядро sing-box и контроллер из пакета в `/media/developer/tv-vpn` (права 0700/0600) и сверит хеш ядра с `core.lock.json`. Автоподключение по умолчанию выключено.
5. **Добавьте профиль** (следующий раздел) и нажмите большую кнопку.

После обновления IPK приложение предложит «Обновить компоненты»; профили и настройки сохраняются, включённый VPN переподключится. Язык приложения — как у телевизора: русский для русского, иначе английский.

### Что проверяет экран установки

Каждый пункт отмечается галочкой или крестиком; при любом крестике VPN на этом ТВ работать не сможет.

| Проверка | Зачем |
|---|---|
| Root (Homebrew Channel «Root OK») | TUN, маршруты и DNS требуют root |
| Процессор ARM | в пакете sing-box `linux-armv7` |
| Node.js 14 или новее | контроллер работает на встроенном Node.js телевизора и использует современный синтаксис (`?.`) |
| `/dev/net/tun` | устройство туннеля |
| `ip rule` | маршрутизация по правилам: трафик в туннель, локальная сеть напрямую |
| `connmanctl` | чтение и восстановление настроек DNS телевизора |

Если ваш ТВ не проходит только проверку Node.js, оставьте [отчёт о совместимости](https://github.com/steam20011972-code/tv-vpn/issues/new?template=compatibility.yml): сборку под старый Node.js сделаем, если она будет нужна.

## Добавление профилей

Откройте карточку профиля → «Добавить профиль».

- **Телефон (QR-код).** Телефон должен быть в той же сети, что и ТВ. Отсканируйте код, вставьте ссылку (`vless`, `vmess`, `trojan`, `ss`, `hysteria2`, `tuic`), несколько ссылок или адрес подписки и нажмите «Добавить». ТВ покажет, сколько профилей добавлено и почему отклонены остальные.
- **Флешка.** Положите текст в файл `tv-vpn.txt` в корне флешки (до 64 КБ), вставьте её в ТВ и выберите «Загрузить с USB». Потом удалите файл: в нём ключи доступа.
- **Подписки.** `http(s)`-адрес, который отдаёт base64-список, обычный список ссылок или JSON sing-box (до 1 МБ). Сервер подписки и каждый редирект должны иметь публичный IPv4-адрес: адреса домашней сети, самого ТВ, link-local и похожие диапазоны отклоняются. На экране профилей у каждой подписки есть «Обновить»; после включения ТВ подписки старше суток обновляются сами. Если у текущего профиля сменились ключи, выбор переходит на профиль с тем же именем.

Пока на экране QR-код, ТВ держит небольшую веб-страницу на своём адресе в локальной сети: обычный HTTP без шифрования, только из частных сетей (10/8, 172.16/12, 192.168/16), не больше 10 запросов в минуту, одноразовый 128-битный токен в адресе. Страница закрывается после первого успешного импорта, через 5 минут или при уходе с экрана и умеет только добавлять профили — маршруты и настройки она не трогает. В недоверенной сети пользуйтесь флешкой.

## Разработка

Нужны: Node.js 20+, SSH-доступ root к ТВ по LAN, ключ ТВ в `~/.ssh/known_hosts`.

```sh
npm install
export TV_HOST=<IP телевизора>
export TV_SSH_PASSWORD=<пароль root>   # только в окружении текущего процесса
```

- `npm test`; `npm run build` — скачивает ядро по `core.lock.json` (`tools/fetch-core.cjs`, проверка SHA256), собирает IPK с runtime и ядром и проверяет хеш ядра внутри пакета.
- Релизные пакеты подписаны (Ed25519, `runtime/signature.cjs`); неподписанный или изменённый пакет ТВ не установит. Сборка подписывает ключом из `TVVPN_SIGNING_KEY`, `TVVPN_SIGNING_KEY_FILE` или `~/.tvvpn/release-signing.key`, CI — секретом репозитория `TVVPN_SIGNING_KEY`. Форку нужна своя пара ключей и свой открытый ключ в `runtime/signature.cjs`. Чтобы поставить свою неподписанную сборку по SSH, запустите `setup.cjs install` с `TVVPN_ALLOW_UNSIGNED=1`.
- CI (`.github/workflows/build.yml`) запускает тесты и сборку на каждый push и pull request. Тег `vX.Y.Z`, совпадающий с версией в `app/appinfo.json`, публикует pre-release с IPK и `.sha256`. Подать пакет в репозиторий Homebrew Channel для установки в один клик планируется после отзывов по beta.
- `node tools/install-app.cjs` — установить IPK и открыть приложение.
- Профиль: `TVVPN_PROFILE_FILE=путь/к/файлу node tools/stage.cjs` или передайте ссылку через stdin. Файл со ссылкой храните вне репозитория и удалите после импорта.
- Без приложения: `node tools/deploy-runtime.cjs` (runtime) и `node tools/set-autostart.cjs on|off`; установка по SSH — `/usr/bin/node /media/developer/apps/usr/palm/applications/<id>/runtime/setup.cjs install|status`.

## Управление

Большая кнопка включает/выключает VPN. Стрелки — фокус, OK — выбор, Back — закрыть диагностику или приложение. «Подключать автоматически» относится к включению ТВ. Закрытие приложения не разрывает соединение.

## Восстановление сети

По SSH на ТВ:

```sh
/usr/bin/node /media/developer/tv-vpn/runtime/ctl.cjs restore-network
```

Если контроллер не отвечает:

```sh
/usr/bin/node /media/developer/tv-vpn/runtime/recover.cjs
```

Отключить автозапуск навсегда:

```sh
/usr/bin/node /media/developer/tv-vpn/runtime/ctl.cjs set-autostart off
/usr/bin/node /media/developer/tv-vpn/runtime/ctl.cjs stop
```

## Удаление

В приложении: «Состояние и диагностика» → «Удалить MEDZH VPN полностью», затем выберите, сохранить ли профиль. Или по SSH:

```sh
/usr/bin/node /media/developer/tv-vpn/runtime/uninstall.cjs
```

Отключается автозапуск, завершаются свои процессы, восстанавливаются DNS и маршруты, удаляются компоненты. Профиль остаётся (права 0600); чтобы удалить и его, добавьте `--delete-profile`. Затем удалите значок MEDZH VPN через меню приложений ТВ.

## Если что-то не работает

Откройте [issue](https://github.com/steam20011972-code/tv-vpn/issues/new/choose) и приложите обезличенный отчёт. По SSH на телевизоре:

```sh
/usr/bin/node /media/developer/apps/usr/palm/applications/io.github.steam20011972-code.tvvpn/runtime/report.cjs
```

Команда только читает файлы и выводит JSON: модель ТВ, версию webOS, результаты проверок, версии приложения и ядра, состояние VPN, названия протоколов и последние коды событий. Имена профилей, серверы, ссылки, адреса подписок, IP-адреса, серийные номера и MAC в него не попадают. Всё равно просмотрите его перед публикацией.

## Безопасность

Профили, ключи и адреса подписок не попадают в Git, IPK, логи и диагностику; на ТВ файлы имеют права 0600, а итог импорта содержит только счётчики. Об уязвимостях — см. [SECURITY.md](SECURITY.md).

# MEDZH VPN

**Нужен телевизор LG webOS с root и Homebrew Channel в состоянии «Root OK».** Без root приложение работать не может: webOS не даёт обычным приложениям создавать TUN, менять маршруты и DNS.

[English](README.md)

VPN-клиент для LG webOS на основе [sing-box](https://github.com/SagerNet/sing-box) (ARMv7) и небольшого контроллера на Node.js, который уже есть на ТВ. Приложение **MEDZH VPN** включает и выключает VPN для всего телевизора, восстанавливает обычную сеть при сбое и умеет подключаться автоматически при включении ТВ.

> **Статус: ранняя версия для разработчиков.** Проверено на одной модели (LG 55UA75009LA, webOS 25). Компоненты ставятся из самого приложения; профили добавляются с телефона по QR-коду или с флешки.

## Дисклеймер

- Программа предоставляется «как есть», без каких-либо гарантий (см. [LICENSE](LICENSE)).
- Root и изменение сетевых настроек ТВ — на ваш риск. Проект не трогает прошивку и системные разделы, но ошибка в сетевых настройках может временно оставить ТВ без интернета (см. «Восстановление сети»).
- Нужен **собственный** VPN-сервер или профиль, которым вы вправе пользоваться. Проект не предоставляет серверов.
- Соблюдайте законы своей страны.

## Что поддерживается сейчас

- Профили (ссылки или outbound из JSON sing-box):
  - `vless://` — без шифрования / TLS / Reality; транспорт TCP, WebSocket (в том числе early data `?ed=`), gRPC, HTTPUpgrade; `flow=xtls-rprx-vision`;
  - `vmess://` (base64 JSON v2rayN, `alterId` 0), `trojan://`, `ss://` (SIP002 и старый base64; шифры AEAD и 2022, без плагинов), `hysteria2://` / `hy2://` (obfs salamander, смена портов), `tuic://`.
  - Параметры сверяются со списком разрешённых: незнакомый параметр отклоняет ссылку, а не отбрасывается молча. Возможности только Xray (xhttp, kcp, VLESS encryption) отклоняются с пояснением «не поддерживается sing-box». Сервер с IPv6-адресом не поддерживается.
  - Сервер может быть доменом: он резолвится обычным DNS телевизора до запуска туннеля. VPN считается подключённым, если trace Cloudflare через туннель показывает адрес сервера или адрес выхода, отличный от прямого адреса ТВ.
- Весь IPv4-трафик ТВ идёт через VPN, DNS — через DoH внутри туннеля. Внешний IPv6 во время VPN блокируется. Локальная сеть доступна.
- Если сервер недоступен, контроллер возвращает обычную сеть и повторяет подключение с паузами до 5 минут. Отдельный watchdog восстанавливает сеть, если контроллер завис.

## Установка

1. Установите IPK `io.github.steam20011972-code.tvvpn_<версия>_all.ipk` (Homebrew Channel, `ares-install` или `node tools/install-app.cjs`).
2. Откройте MEDZH VPN. Приложение проверит root, `/dev/net/tun`, `ip rule`, ConnMan и Node.js и предложит «Установить компоненты». Ядро sing-box и контроллер копируются из пакета в `/media/developer/tv-vpn` (права 0700/0600), хеш ядра сверяется с `core.lock.json`. Автоподключение по умолчанию выключено.
3. После обновления IPK приложение предложит «Обновить компоненты»; профиль и настройки сохраняются, включённый VPN переподключится.

Без root приложение покажет «Нужен Homebrew Channel с Root OK».

## Добавление профилей

Откройте карточку профиля → «Добавить профиль».

- **Телефон (QR-код).** Телефон должен быть в той же сети, что и ТВ. Отсканируйте код, вставьте ссылку (`vless`, `vmess`, `trojan`, `ss`, `hysteria2`, `tuic`), несколько ссылок или адрес подписки и нажмите «Добавить». ТВ покажет, сколько профилей добавлено и почему отклонены остальные.
- **Флешка.** Положите текст в файл `tv-vpn.txt` в корне флешки (до 64 КБ), вставьте её в ТВ и выберите «Загрузить с USB». Потом удалите файл: в нём ключи доступа.
- **Подписки.** `http(s)`-адрес, который отдаёт base64-список, обычный список ссылок или JSON sing-box (до 1 МБ). На экране профилей у каждой подписки есть «Обновить»; после включения ТВ подписки старше суток обновляются сами. Если у текущего профиля сменились ключи, выбор переходит на профиль с тем же именем.

Пока на экране QR-код, ТВ держит небольшую веб-страницу на своём адресе в локальной сети: обычный HTTP без шифрования, только из частных сетей (10/8, 172.16/12, 192.168/16), не больше 10 запросов в минуту, одноразовый 128-битный токен в адресе. Страница закрывается после первого успешного импорта, через 5 минут или при уходе с экрана и умеет только добавлять профили — маршруты и настройки она не трогает. В недоверенной сети пользуйтесь флешкой.

## Разработка

Нужны: Node.js 18+, SSH-доступ root к ТВ по LAN, ключ ТВ в `~/.ssh/known_hosts`.

```sh
npm install
export TV_HOST=<IP телевизора>
export TV_SSH_PASSWORD=<пароль root>   # только в окружении текущего процесса
```

- `npm test`; `npm run build` — скачивает ядро по `core.lock.json` (`tools/fetch-core.cjs`, проверка SHA256), собирает IPK с runtime и ядром и проверяет хеш ядра внутри пакета.
- `node tools/install-app.cjs` — установить IPK и открыть приложение.
- Профиль: `TVVPN_PROFILE_FILE=путь/к/файлу node tools/stage.cjs` или передайте ссылку через stdin. Файл со ссылкой храните вне репозитория и удалите после импорта.
- Без приложения: `node tools/deploy-runtime.cjs` (runtime) и `node tools/set-autostart.cjs on|off`; установка по SSH — `/usr/bin/node /media/developer/apps/usr/palm/applications/<id>/runtime/setup.cjs install|status`.

## Управление

Большая кнопка включает/выключает VPN. Стрелки — фокус, OK — выбор, Back — закрыть диагностику или приложение. «Подключать автоматически» относится к включению ТВ. Закрытие приложения не разрывает соединение.

## Восстановление сети

По SSH на ТВ:

```sh
/usr/bin/node /media/developer/tv-vpn/runtime/ctl.cjs restore-network
```

Если контроллер не отвечает:

```sh
/usr/bin/node /media/developer/tv-vpn/runtime/recover.cjs
```

Отключить автозапуск навсегда:

```sh
/usr/bin/node /media/developer/tv-vpn/runtime/ctl.cjs set-autostart off
/usr/bin/node /media/developer/tv-vpn/runtime/ctl.cjs stop
```

## Удаление

В приложении: «Состояние и диагностика» → «Удалить MEDZH VPN полностью», затем выберите, сохранить ли профиль. Или по SSH:

```sh
/usr/bin/node /media/developer/tv-vpn/runtime/uninstall.cjs
```

Отключается автозапуск, завершаются свои процессы, восстанавливаются DNS и маршруты, удаляются компоненты. Профиль остаётся (права 0600); чтобы удалить и его, добавьте `--delete-profile`. Затем удалите значок MEDZH VPN через меню приложений ТВ.

## Безопасность

Профили, ключи и адреса подписок не попадают в Git, IPK, логи и диагностику; на ТВ файлы имеют права 0600, а итог импорта содержит только счётчики. Об уязвимостях — см. [SECURITY.md](SECURITY.md).
